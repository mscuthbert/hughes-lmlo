This repo contains the contents of the disks from Andrew Hughes' Late Medieval Liturgical Offices.

They have been uploaded here with permission from the Pontifical Institute for Medieval Studies (PIMS).

If you are looking for an archived version of the disks themselves, they have been uploaded to the Internet Archive: https://archive.org/details/lmlo-disks

You will likely need an MS-DOS emulator to run the software. [DOSBox-X](https://dosbox-x.com) has been successfully tested and seems to work.
